# Specifications

This section acts as a reference and resource which describes binary formats
discovered while extracting and reverse-engineering game data from PS1 titles.

Information is based on _analysis_ of structured game data through
reverse-engineering. Information is not guaranteed to be correct; it may be
subject to change as new information is discovered. Each page provides a badge
indicating the estimated completeness of the information it contains.
